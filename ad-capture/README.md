# Ads Capture → PowerPoint

เครื่องมือนี้อ่านรายชื่อ Ads + Link จากไฟล์ Excel แล้วแคปภาพหน้าจอของแต่ละลิงก์
อัตโนมัติ จากนั้นรวมเป็นไฟล์ PowerPoint (.pptx) ให้เลย

## วิธีใช้งาน (ครั้งแรก)

1. ติดตั้ง [Node.js](https://nodejs.org) (เวอร์ชัน 18 ขึ้นไป)
2. เปิด terminal ในโฟลเดอร์นี้ แล้วรัน:
   ```
   npm install
   npm run setup
   ```
   (ขั้นตอนนี้ติดตั้งเบราว์เซอร์ที่ใช้แคปภาพ ทำครั้งเดียว)

## วิธีใช้งาน (ทุกครั้ง)

1. นำไฟล์ Excel ที่ทีมกรอก (ตาม template ใน `input/ads.template.xlsx`) มาวางที่
   `input/ads.xlsx`
   - คอลัมน์ที่ต้องมี: `NAME` (ชื่อ ads, ไม่บังคับ), `TYPE`, `URL`
2. รันคำสั่ง:
   ```
   npm start
   ```
3. รอจนเสร็จ จะได้ไฟล์ `output/Ads_Capture_xxxx.pptx`

## ปรับเวลารอโฆษณาโหลด

ค่าเริ่มต้นคือรอ 8 วินาทีต่อ 1 ลิงก์ ก่อนแคปภาพ ถ้าต้องการเพิ่ม/ลด:

```
WAIT_SECONDS=15 npm start
```

## ข้อจำกัด

- ลิงก์ที่ต้อง **login** ก่อนถึงจะดูได้ จะแคปไม่ได้ (จะได้หน้า login แทน)
- โฆษณาวิดีโอบางแพลตฟอร์มต้องกด Play เอง — ระบบพยายามกดปุ่ม Play ให้อัตโนมัติ
  แต่ถ้าปุ่มไม่ตรงกับรูปแบบที่รู้จัก อาจต้องปรับ selector ใน `capture.js`
- ถ้าโฆษณาไม่ขึ้น (เช่น ติด frequency cap/geo targeting) ภาพที่ได้อาจเป็นหน้า
  คอนเทนต์ปกติแทนโฆษณา
