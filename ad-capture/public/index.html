📸 Ads Capture DV360 → PowerPoint

อัปโหลด Excel ที่มี NAME, TYPE, URL แล้วระบบจะแคปภาพโฆษณาและสร้าง PowerPoint อัตโนมัติ

🖥️ Server Capture
• server เปิด browser แคปให้
• ใช้ IP ของ Render (cloud)
⚠ YouTube มักโดน bot-check
✅ เว็บทั่วไปใช้ได้ปกติ
📷 My Browser Capture
• browser คุณแคปเอง
• ใช้ IP และ session ของคุณ
✅ YouTube / WeTV / Viu ผ่าน
• ต้องแชร์หน้าจอ 1 ครั้ง
วิธีใช้งาน My Browser Capture:
1️⃣ เลือกไฟล์ Excel → กด โหลดรายการ (สูงสุด 10 รายการ)
2️⃣ ตั้งเวลารอต่อ URL → กด เริ่ม Capture
3️⃣ หน้าต่าง "Ads Capture Display" เปิดขึ้น → เมื่อถูกถามให้แชร์ เลือก Window → Ads Capture Display → Share
4️⃣ กลับมา tab นี้ ระบบแคปให้อัตโนมัติ → ดาวน์โหลด PPTX
ตั้งเวลารอต่อ URL (วินาที) — YouTube แนะนำ 10+ วินาที
