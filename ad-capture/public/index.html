• server เปิด browser แคปให้
• ใช้ IP ของ Render (cloud)
⚠ YouTube มักโดน bot-check
✅ เว็บทั่วไปใช้ได้ปกติ
📷 My Browser Capture
• browser คุณแคปเอง
• ใช้ IP และ session ของคุณ
✅ YouTube ผ่าน
• ต้องแชร์หน้าจอ 1 ครั้ง
วิธีใช้งาน My Browser Capture (YouTube เท่านั้น):
1️⃣ เลือกไฟล์ Excel ที่มี URL ของ YouTube → กด โหลดรายการ (สูงสุด 10 รายการ)
2️⃣ ตั้งเวลารอต่อ URL (แนะนำ 15+ วินาทีสำหรับ YouTube) → กด เริ่ม Capture
3️⃣ เมื่อถูกถามให้แชร์หน้าจอ → เลือก Entire Screen → กด Share
4️⃣ อย่าคลิกอะไร! หน้าต่างโฆษณาจะเปลี่ยน URL ให้เองอัตโนมัติ → ดาวน์โหลด PPTX
